**Промпт:** Отправлена документация + "В файле представлена документация для api футбольных матчей, доматчевые и live коэффициенты, статистика, профиты, Glicko 2. Напиши программу на Go для сбора спортивной статистики с API api.sstats.net. Сделай это в папке collector в корне проекта. В корне проекта создай файлы .env и .env.example с переменной SSTATS_API_KEY и базовым URL. Программа должна считывать эти конфигурации из корня, выполнять авторизацию в соответствии со спецификацией API, запрашивать список стран через GET /pari/countries и параллельно опрашивать GET /pari/leagues для каждой страны с помощью горутин. Полученные объекты лиг необходимо записывать в файл collector/leagues_raw.json в формате JSON Lines, где каждый объект расположен на отдельной строке.
